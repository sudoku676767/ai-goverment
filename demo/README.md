# 政务公文智核 · 宣传视频演示原型

单个 HTML 文件，双击用 Chrome 或 Edge 打开即可，不需要联网，也不需要安装任何东西。所有公文、人名、电话、文件和数字都是虚构的。

- 画面按 1920×1080（16:9）设计，会自动缩放到窗口大小。录屏时按 F11 全屏，效果最好。
- 数字键 1–9 可以直接切换页面。
- 刷新页面会恢复初始状态，每条镜头录完可以刷新再录。
- 审计链用浏览器里真实的 SHA-256 计算。篡改演示里，被改的那条记录哈希确实对不上，不是写死的动画。

## 镜头与操作对照

| 镜号 | 页面（按键） | 操作 |
| --- | --- | --- |
| 4 | 系统架构（1） | 连续点“逐层展示 ▶”五次，从用户层亮到模型层 |
| 5 | 公文起草（2） | 点“生成初稿”，等正文打完 |
| 6 | 公文校核（3） | 点“开始校核”，依次出现规则 5 处、模型 3 处、知识库 1 处 |
| 7 | 公文校核（3） | 逐条点“采纳”（可以挑一条点“驳回”），计数归零后点“定稿并导出 Word” |
| 8 | 口径比对与解读（4） | 口径比对标签页里，依次点三条，看“不一致”和“一致” |
| 9 | 口径比对与解读（4） | 切到“政策问答”，点“提问”，再点回答里的出处标记 |
| 10 | 会议纪要（5） | 点“生成纪要”，注意“待确认”两处 |
| 11 | 敏感信息保护（6） | 依次点 ①②③④，最后停在底部的审计日志 |
| 12 | 分级访问控制（7） | 点“两人同时提问”；再点左上红色按钮，出现拦截页 |
| 13 | 审计记录（8） | 先点“完整性校验”（全绿），再点“模拟篡改一条记录”，再点“完整性校验”（红色报错） |
| 14 | 评测看板（9） | 停留展示；数字目前是示例值，待换成试点实测 |
| 15 | 系统架构（1） | 点“全部显示”，再点“切换模型（演示可替换）” |

镜头 13 也可以换成终端里真实运行黑匣子的 `verify` 命令，两种都能拍。
